# agent-prd：用 AI 把你的 Agent 点子变成需求文档和技术方案

你只需要有一个想法，比如「想做个 AI 帮我妈记账」。AI 会一次问你一个问题，问清楚后给你写出两份文件：

- **`PRD.md`**：需求文档。做什么、给谁用、不能做什么、怎样算做成。
- **`方案.md`**：技术方案。这个 AI 产品该怎么搭、有哪些功能模块、怎么防出错。

这两份文件是写给 AI 看的：以后让任何 AI 编程工具照着它们开发就行。

不用装任何软件，也不用申请 API Key。说不清的地方直接说「不知道」，它会记成待确认问题，你之后再回答。

> 只适合 **AI Agent 类**的点子：AI 要自己理解你的话、去查资料或调用工具、做判断、交出结果（客服、助理、自动整理、审核、陪练……）。普通网站或 App 用它会不太合适，它会先提醒你。

## 按你用的 AI 工具选一种装法

### Claude Code

在终端里运行一条命令（会同时装上负责开发环节的 agent-builder）：

```bash
claude plugin install agent-workshop --marketplace hubooooooo/agent-workshop
```

或者只要这一个技能：把整个 `agent-prd` 文件夹复制到 `~/.claude/skills/` 下面。

装好后直接说出你的想法，它会自动开始。

### claude.ai 网页版 / Claude 桌面或手机 App

1. 下载 `agent-prd.skill`。
2. 在设置里找到「技能（Skills）」，上传这个文件并打开它。需要先打开「代码执行」功能。
3. 新开一个对话，说出你的想法。

### 其他 AI 编程工具（Codex、Cursor、Trae、通义灵码等）

1. 下载 `agent-prd.zip` 并解压，把 `agent-prd` 文件夹放进你的项目文件夹。
2. 对 AI 说：

   ```text
   先读 agent-prd/SKILL.md，按里面的流程帮我把这个点子整理成 PRD 和技术方案：
   （你的想法）
   ```

### 普通聊天网页（不能读文件夹的 AI）

把 `SKILL.md` 和 `references/` 文件夹里的所有 `.md` 文件一起上传，然后说：

```text
请按 SKILL.md 的流程（参考资料在其他上传的文件里）帮我把这个点子整理成 PRD 和技术方案：
（你的想法）
```

这种情况下 AI 运行不了选型脚本，会按参考资料里的规则手工推导，结果一样。两份文档会直接显示在对话里，按它的提示复制保存成 `PRD.md` 和 `方案.md`。

## 之后可以继续说

- 「我来回答方案里的问题」：一题一题回答，答案会写进 PRD，方案跟着更新。
- 「再加一个功能：……」：PRD 升一版，方案里写明这一版改了什么。
- 「按 PRD.md 和 方案.md 开始开发」：进入开发环节，这一步就不归 agent-prd 管了。
