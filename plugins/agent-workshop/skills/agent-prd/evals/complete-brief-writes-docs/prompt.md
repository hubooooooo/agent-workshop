我想做一个帮社区面包店回复顾客微信消息的 AI 客服。
给谁用：面包店老板（我表姐）开的店，顾客在微信上问今天有什么面包、价格、能不能预订。
流程：顾客发消息 → AI 查今天的面包清单和价格 → 回复顾客；顾客要预订时，AI 记下要什么、几个、什么时候取，然后发给老板确认，老板确认了才算订上。
怎样算成功：老板每天少回一半以上的重复问题。
不能做的：不能自己改价格、不能答应清单上没有的面包、不能替老板收钱。AI 不确定的时候就说"我问一下老板"。
面包清单老板每天早上会在一个表格里更新。

信息就这些，你不用再问我了，直接帮我出需求文档和技术方案。
